## 游戏概述

CDDA 是一款基于 Java 17 Swing 开发的 2D 回合制卡牌/策略游戏引擎。游戏采用**回合制时间系统**，时间仅在玩家行动时流逝。核心体验围绕**生存**展开——玩家需要在动态变化的自然环境中管理体温、代谢、水分和饥饿，通过采集、狩猎、种植和制作来维持生存。

### 技术规格

| 项目 | 数值 |
|------|------|
| 窗口尺寸 | 600 × 400 像素（固定） |
| 渲染帧率 | ~30 FPS |
| 区块大小 | 32 × 32 瓦片 |
| 区域大小 | 4 × 4 区块 |
| 地图大小 | 64 × 64 瓦片（默认） |

## 世界生成

世界通过 **Perlin 噪声**算法按需生成，采用无限区块架构，支持动态加载和卸载。

### 生成参数

- **种子**：默认使用当前时间戳，可自定义
- **地图尺寸**：默认 64×64 瓦片
- **方向梯度**：~2000 区块尺度的宏观地形变化
- **生物群落驱动**：大地图（WorldMap）为每个区块分配生物群落，区块生成时根据群落的密度参数放置地表物体

### 生成层级

```
WorldMap（生物群落分配）
  → Region（4×4 区块）
    → Chunk（32×32 瓦片）
      → Tile（1×1 瓦片）
```

### 能量系统

动物通过觅食/狩猎/拾荒获取能量。能量低于阈值时无法繁殖，能量耗尽则死亡。

- **草食动物**：通过 `grazeGain`（啃食）获取能量
- **肉食动物**：通过 `huntGain`（狩猎）和 `scavengeGain`（拾荒）获取能量
- **顶级掠食者**（狼）：`huntGain=25`，可猎杀其他动物

### AI 行为

动物 AI 为状态机，包含 6 种状态：

| 状态 | 持续时间 | 说明 |
|------|----------|------|
| **IDLE**（待机） | 3-8 回合 | 静止休息 |
| **WANDER**（游荡） | 2-5 回合 | 随机移动探索 |
| **GRAZE**（觅食） | 3-6 回合 | 啃食植被获取能量 |
| **FLEE**（逃跑） | 无限（直到安全） | 逃离玩家，受耐力影响 |
| **HUNT**（狩猎） | 无限（直到成功/丢失） | 追击猎物，障碍物规避 |
| **SCAVENGE**（拾荒） | 5-10 回合 | 40% 基础成功率 |

**状态转换规则**：
- 饥饿 → 草食动物选择 GRAZE，肉食动物选择 HUNT
- 肉食动物有 40% 概率选择狩猎
- 草食动物有 50% 概率选择觅食
- 默认：50/50 游荡/觅食

**逃跑机制**（仅草食动物）：
- 评估 8 个方向，根据"远离玩家"（权重×8）和"前方开阔度"评分
- 耐力耗尽时 80% 概率移动失败
- 耐力 < 10% 或距离安全线 ≥ 10 瓦片时停止逃跑

**狩猎机制**：
- 寻找视野内最近的能量 > 10 的猎物
- 优先轴向移动，受阻时横向绕行
- 捕食成功率 = `0.5 + (捕食者敏捷 - 猎物敏捷) × 0.02`（20%-90%）

**陷阱感知**：基于视觉和 HP 有概率发现并避开陷阱
- 小型（HP≤10）：5-10%
- 中型（HP≤30）：10-20%
- 大型（HP>30）：15-35%+

### 耐力系统

逃跑时消耗耐力（每步 2 点），速度根据耐力比例提升（最高 +50%）。耐力低于阈值时移动成功率大幅下降。

玩家是游戏的核心控制实体，拥有完整的属性和系统。

| 属性 | 初始值 | 说明 |
|------|--------|------|
| 生命值 (HP) | 100/100 | 受到伤害降至 0 时死亡 |

| 敏捷 (Agility) | 10 | 影响行动效率 |
| 耐力 (Endurance) | 10 | 影响体力恢复 |
| 速度 (Speed) | 100 | 决定每轮可执行的行动次数 |
| 视觉范围 | 10 瓦片 | 可见范围 |
| 听觉范围 | 8 瓦片 | 可感知声音的范围 |

### 战斗系统

- **基础伤害** = 力量 / 2（至少 1 点）
- **浮动范围** = ±20%
- **武器加成**：
  - 石矛：+10
  - 木矛：+6
  - 石斧：+5
  - 小刀：+3

### 角色设定

- **名称**：默认"旅行者"，最长 20 字符
- **性别**：男 / 女

## 生存系统

### 温度系统

三层环境温度模型：

1. **月均温**：基于月份的基础温度
2. **日内正弦波动**：14:00 达到峰值，02:00 达到谷值，振幅 ±3°C
3. **平滑随机漂移**：±2°C 范围，600 秒平滑过渡

**舒适区**：16°C ~ 26°C
- 偏离舒适区每°C额外消耗 3 cal/秒的环境代偿热量

### 代谢系统

| 参数 | 数值 | 说明 |
|------|------|------|

| 基础代谢率 | 9 cal/回合 | ~800 kcal/天 |
| 移动热量消耗 | 120 cal/步 | 步行消耗 |
| 正常体温 | 37°C | 人体核心温度 |
| 体温缓冲 | 最大 5000 | 有能量时延缓体温偏离 |

## 生态系统

### 能量流动

动物之间通过食物链传递能量，能量转移效率为 **20%**（捕食者获得猎物能量的 20%）。

| 死亡原因 | 能量转移 | 掉落 |
|----------|----------|------|
| 自然死亡（年龄/饥饿） | 能量回流植被，尸体分解 | 无 |
| 被猎食 | 直接转移给捕食者 | 无 |
| 玩家击杀 | 无能量转移 | 掉落战利品 |

**尸体分解**会提升植被密度（最高 +0.3），随时间以 5%/tick 衰减。

### 迁徙生成

每 100 回合检查玩家周围 3×3 区块。若某区块总能量回流 ≥ 200，有概率生成次级消费者或顶级掠食者。每个区块最多 2 只顶级掠食者。

### 现实气泡

- **半径**：40 瓦片（曼哈顿距离）
- 气泡内的生物执行 AI 逻辑
- 气泡外的生物仅每 500 回合检查一次繁殖
- AI 计算在后台线程异步执行，通过变更队列（Mutation Queue）同步到主线程

### 生物密度限制

同一物种在 5 瓦片范围内最多 **4 只**，防止物种过度繁殖。

### 陷阱感知

动物基于视觉和 HP 有概率发现并避开陷阱：
- 小型（HP≤10）：5-10% 发现率
- 中型（HP≤30）：10-20% 发现率
- 大型（HP>30）：15-35%+ 发现率

## 空间索引

### CreatureGrid

基于区块的空间哈希映射（`ConcurrentHashMap<Long, List<Creature>>`），区块大小 32 瓦片。

| 操作 | 复杂度 |
|------|--------|
| 添加/移除 | O(1) |
| 瓦片查询 | O(1) |
| 半径查询（曼哈顿） | O(可见区块数) |
| 同物种密度检查 | O(1)（检查周围 9 区块） |

## 时间与日历

### 日历规则

- **一年** = 12 个月 × 30 天 = 360 天
- **一天** = 24 小时 × 60 分钟
- **时间推进**：仅在玩家行动时流逝（回合制）

### 四季

| 季节 | 月份 | 特征 |
|------|------|------|
| **春季** | 3-5月 | 温度回暖，植物生长 |
| **夏季** | 6-8月 | 高温，水分流失快 |
| **秋季** | 9-11月 | 温度下降，收获季节 |
| **冬季** | 12-2月 | 寒冷，植物停止生长 |

### 时间常量

| 常量 | 值 | 说明 |
|------|-----|------|
| ENTITY_DEFAULT_SPEED | 100 | 默认实体速度 |

| MOVE_COST | 100 | 每次行动消耗移动点数 |
| TEMP_DAILY_AMPLITUDE | 3.0°C | 日内温度波动振幅 |

## MOD 系统

游戏支持完整的 Mod 扩展能力：

### 可扩展内容

| 内容 | 扩展方式 |
|------|----------|
| **生物群落** | `BiomeType.registerMod()` |
| **地形类型** | `TileType.registerMod()` |
| **植被** | JSON 配置文件，自动加载 |
| **动物** | JSON 配置文件，自动加载 |
| **物品** | JSON 配置文件，自动加载 |
| **配方** | JSON 配置文件，自动加载 |
| **物品动作** | 实现 `ItemAction` 接口并注册 |

### Mod 格式

Mod 通过 `ModLoader` 加载，包含 `ModManifest` 描述文件。资源可放置在独立目录中，通过 `file:path` 前缀加载外部资源。

### 资源路径约定

- `classpath:path` — 程序内资源（JAR 中）
- `file:path` — 外部文件资源
- 无前缀 — 自动检测（优先 classpath）
