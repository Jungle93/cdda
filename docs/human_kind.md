# 角色属性系统

> 本文档定义角色的完整属性体系。基础属性由**地域背景**提供基线值 + 天赋修正决定，所有二级属性由基础属性推导而来，形成联动关系。

---

## 一、地域背景系统

### 设计理念

所有角色都是**人类**，没有幻想种族。差异来源于角色**成长的环境**——不同地区的气候、资源、生活方式塑造了不同的体质、技能和装备偏好。

```
基础属性初始值 = 地域基线值 + 天赋修正值
```

### 地域模板

每个地域背景定义以下数据：

| 字段 | 说明 |
|------|------|
| `id` | 唯一标识（如 `northern_highlands`, `coastal_plains`） |
| `name` | 显示名称（如"北方高地人"、"沿海平原人"） |
| `description` | 地域描述、地理特征、生活方式 |
| `baseAttributes` | 六大基础属性的基线值（1~20） |
| `attributeModifiers` | 地域修正值（可正可负，反映环境塑造的体格差异） |
| `startingGear` | 起始装备列表（反映当地材料和工艺） |
| `survivalModifiers` | 生存系数修正（代谢、温度耐受等） |
| `skillBonuses` | 初始技能加成（反映当地常见生产方式） |

### 地域示例

| 地域背景 | STR | AGI | CON | INT | PER | WIL | 起始装备特征 |
|---------|-----|-----|-----|-----|-----|-----|-------------|
| **普通人** | 10 | 10 | 10 | 10 | 10 | 10 | 无修正，均衡 |
| **北方高地人** | 12 | 8 | 14 | 10 | 8 | 12 | 厚实毛皮、粗制石斧、耐储干肉 |
| **南方河谷人** | 10 | 12 | 8 | 12 | 10 | 8 | 轻薄麻衣、骨制渔叉、编织篮 |
| **东部林居人** | 8 | 14 | 8 | 8 | 14 | 10 | 树皮斗篷、木制短弓、草药包 |
| **西部草原人** | 14 | 10 | 12 | 8 | 12 | 10 | 皮革护甲、投石索、风干奶酪 |
| **山地矿工** | 14 | 6 | 16 | 10 | 8 | 12 | 铁镐、矿灯、厚手套 |

### 地域生存修正

| 地域背景 | 代谢系数 | 饥饿耐受 | 水分流失抗性 | 御寒修正 | 耐热修正 |
|---------|---------|---------|-------------|---------|---------|
| 普通人 | 1.0 | 0% | 0% | 0 | 0 |
| 北方高地人 | 0.85 | +10% | +5% | +3 | -2 |
| 南方河谷人 | 1.15 | -5% | +10% | -3 | +3 |
| 东部林居人 | 1.0 | +5% | +5% | 0 | 0 |
| 西部草原人 | 1.05 | +15% | -5% | +2 | -2 |
| 山地矿工 | 1.0 | +10% | 0% | +1 | 0 |

### 地域与世界的关系

地域背景不是"种族"，而是角色出生地的标签。它与地图生成的**方向梯度系统**联动：
- **北方高地人**出生在北方寒冷高海拔区域，天然适应山地/高原地形
- **南方河谷人**出生在南方温暖低地，适应平原/沼泽
- **东部林居人**出生在东部湿润林区，适应森林/密林
- **西部草原人**出生在西部干燥地带，适应草原/沙漠边缘

角色的地域背景决定了他们的起始位置和初始装备，但不限制他们在世界中活动。

## 二、基础属性（一级属性）

基础属性是属性树的根节点，范围为 **1~20**（地域背景修正后可超出）。所有二级属性由它们推导。

| 属性 | 英文 | 缩写 | 决定 |
|------|------|------|------|
| **力量** | Strength | STR | 近战伤害、负重上限、投掷距离 |
| **敏捷** | Agility | AGI | 移动速度、闪避率、攻击速度、攀爬速度 |
| **体质** | Constitution | CON | 生命值上限、体力上限、饥饿/口渴基础流失速度 |
| **智力** | Intelligence | INT | 制作/建造效率、陷阱判定成功率、技能学习速度 |
| **感知** | Perception | PER | 视野范围、隐藏资源发现率、夜间可视距离 |
| **意志** | Willpower | WIL | 精神值上限、异常状态抗性、极端环境心理耐受 |

### 成长规则

- 每升级获得 **0~1 点**基础属性成长（按职业方向）
- 每 **10 级**获得 1 点自由分配

## 三、生存属性（核心状态条）

### 生命值（HP）

| 项目 | 公式 |
|------|------|
| **上限** | `50 + CON × 10 + 等级 × 5` |
| **自然恢复** | `0.5 + CON × 0.1` 点/分钟（饥饿值、口渴值均 ≥ 50% 时） |
| **停止恢复** | 饥饿值或口渴值 < 30% |
| **饥饿/口渴同时 < 10%** | HP 每分钟 -1 |

### 体力（Stamina）

| 项目 | 公式 |
|------|------|
| **上限** | `30 + CON × 5 + STR × 2` |
| **自然恢复** | `2 + CON × 0.2` 点/秒（站立/坐下状态） |
| **力竭** | 体力归零 → 10 秒内移动速度 -70%，无法奔跑和攻击 |

**体力消耗速率**：

| 动作 | 消耗 |
|------|------|
| 行走 | 0.5 点/秒 |
| 奔跑 | `2 + 负重比 × 3` 点/秒 |
| 战斗攻击 | 5~15 点/次（按武器重量） |
| 攀爬 | `3 + 负重比 × 4` 点/秒 |
| 砍树/挖矿 | 8 点/次 |

### 饥饿值（Hunger）

| 项目 | 值 |
|------|------|
| **上限** | 100（固定） |
| **基础流失** | 0.8 点/分钟 |

**流失速率** = `基础流失 × 运动系数 × 温度系数 × 代谢系数`

| 系数 | 取值 |
|------|------|
| 运动系数 | 站立 1.0 / 行走 1.2 / 奔跑 1.8 / 战斗 2.0 / 力竭 0.5 |
| 温度系数 | 舒适区间 1.0，每偏离 5℃ +0.15 |
| 代谢系数 | 普通 1.0 / 低代谢 0.85 / 高代谢 1.1 |

**归零惩罚**：每分钟扣最大 HP 的 2%，体力恢复速率 -50%

### 口渴值（Thirst）

| 项目 | 值 |
|------|------|
| **上限** | 100（固定） |
| **基础流失** | 1.2 点/分钟 |

**流失速率** = `基础流失 × 运动系数 × 体温系数 × 湿度系数`

| 系数 | 取值 |
|------|------|
| 运动系数 | 站立 1.0 / 行走 1.3 / 奔跑 2.0 / 战斗 2.5 |
| 体温系数 | 正常 1.0，每高于正常值 1℃ +0.2 |
| 湿度系数 | 高湿度 0.9 / 干燥 1.2 / 沙漠 1.5 |

**归零惩罚**：每分钟扣最大 HP 的 4%，体力上限临时 -30%

### 体温（Body Temperature）

真实温度值（℃），正常区间 **36.0 ~ 37.5℃**。

**体温变化** = `环境温度影响 + 衣物保温值 + 食物热效应 + 运动产热`

| 分项 | 公式 |
|------|------|
| 环境温度影响 | `(环境温度 - 37) × 0.05` ℃/分钟 |
| 衣物保温值 | `装备保温系数之和 × 0.1` ℃/分钟 |
| 食物热效应 | `食物热量 × 0.001` ℃/分钟（持续 10 分钟） |
| 运动产热 | 行走 +0.02 / 奔跑 +0.08 / 战斗 +0.12 ℃/分钟 |

**惩罚表**：

| 区间 | 效果 |
|------|------|
| 35~36℃ | 轻度失温，体力恢复 -20% |
| 33~35℃ | 中度失温，移动速度 -30%，攻击力 -20%，HP -1/分钟 |
| < 33℃ | 重度失温，移动速度 -60%，无法奔跑，HP -3/分钟 |
| 37.5~38.5℃ | 轻度中暑，口渴流失 +30% |
| 38.5~40℃ | 中度中暑，体力消耗 +50%，视野模糊 |
| > 40℃ | 重度中暑，HP -4/分钟，可能晕厥 |

### 精神值（Sanity）

| 项目 | 公式 |
|------|------|
| **上限** | `50 + WIL × 5` |

**流失来源** = `黑暗系数 + 孤独系数 + 恐惧系数 + 环境系数`

| 来源 | 值 |
|------|------|
| 黑暗（完全黑暗） | 0.5 点/分钟 |
| 黑暗（昏暗） | 0.1 点/分钟 |
| 孤独（72h 无交互） | +0.2 点/分钟 |
| 恐惧（附近有敌对生物） | +0.3 点/分钟（按威胁浮动） |
| 环境（暴风雨/暴风雪） | +0.3 点/分钟 |
| 环境（地震） | +0.5 点/分钟 |

**恢复**：

| 方式 | 速率 |
|------|------|
| 安全环境休息 | `2 + WIL × 0.1` 点/分钟 |
| 睡眠 | `5 + WIL × 0.3` 点/分钟 |
| 社交互动 | 10~30 点（按 NPC 好感度） |

**惩罚表**：

| 阈值 | 效果 |
|------|------|
| < 70% | 轻微焦虑，视野边缘暗影 |
| < 50% | 幻觉出现 |
| < 30% | 恐慌发作，颤抖，命中率 -40% |
| < 10% | 精神崩溃，失控奔跑到体力耗尽 |

## 四、战斗属性

### 伤害

| 类型 | 公式 |
|------|------|
| **近战伤害** | `25（徒手基础） + STR × 1.5 + 武器伤害` |
| **远程伤害** | `武器伤害 + AGI × 0.5 + 弹药伤害` |
| **远程衰减** | `1 - (当前距离 / 最大射程) × 0.5` |
| **最终伤害** | `原始伤害 × 暴击倍率 × (1 - 减伤率)` |

### 防御

| 类型 | 公式 |
|------|------|
| **物理防御** | `护甲值 + CON × 0.5` |
| **减伤率** | `物理防御 / (物理防御 + 50 + 攻击者等级 × 5)` |
| **穿刺抗性** | `护甲穿刺系数 × 物理防御` |
| **钝击抗性** | `护甲钝击系数 × 物理防御` |
| **切割抗性** | `护甲切割系数 × 物理防御` |

**护甲材质系数**：

| 材质 | 穿刺 | 钝击 | 切割 |
|------|------|------|------|
| 皮甲 | 0.6 | 0.5 | 0.8 |
| 锁子甲 | 0.8 | 0.4 | 0.9 |
| 板甲 | 0.9 | 0.7 | 1.0 |

### 暴击 / 命中 / 闪避

| 属性 | 公式 |
|------|------|
| **暴击率** | `5% + PER × 0.5% + 装备加成` |
| **暴击倍率** | `1.5 + STR × 0.02 + 装备加成` |
| **命中率** | `80% + PER × 1% + AGI × 0.5% - 目标闪避率`（10%~95%） |
| **闪避率** | `AGI × 1.5% + 装备加成`（上限 40%） |

### 格挡 / 先手

| 属性 | 公式 |
|------|------|
| **格挡率** | `盾牌格挡值 + AGI × 0.3%` |
| **格挡减伤** | `盾牌减伤值 + CON × 0.5%` |
| **先手值** | `AGI × 3 + PER × 1 + 武器重量修正` |

武器重量修正：轻武器 +5 / 中武器 0 / 重武器 -10

### 攻击速度

`基础攻速 × (1 + AGI × 0.02 + 装备攻速加成)`

| 武器 | 基础攻速 |
|------|---------|
| 匕首 | 1.5 次/秒 |
| 短剑 | 1.2 次/秒 |
| 长刀/斧 | 1.0 次/秒 |
| 长矛/大锤 | 0.7 次/秒 |

**格挡/闪避优先级**：先判定闪避 → 闪避失败判定格挡 → 格挡失败承受全额伤害

## 五、环境适应属性

| 属性 | 公式 | 说明 |
|------|------|------|
| **御寒值** | `装备保温系数之和 + CON × 0.5 + 食物热效应` | 参与体温计算 |
| **耐热值** | `装备散热系数之和 + CON × 0.3` | 散热系数为负值 |
| **负重上限** | `STR × 5 + CON × 3`（公斤） | 超重有惩罚 |
| **水分流失抗性** | `CON × 0.5% + 装备加成 + 地域加成` | 乘到口渴流失速率 |
| **饥饿耐受** | `CON × 0.3% + 地域加成` | 乘到饥饿流失速率 |
| **毒素抗性** | `CON × 1% + WIL × 0.5%` | 影响中毒概率和伤害减免 |
| **疾病抗性** | `CON × 0.8% + WIL × 0.3% + 营养均衡修正` | 营养均衡 +10%，营养不良 -20% |

### 负重惩罚

| 超标比例 | 惩罚 |
|---------|------|
| 0%~20% | 无惩罚 |
| 20%~50% | 移动速度 -20%，体力消耗 +30% |
| 50%~100% | 移动速度 -50%，体力消耗 +80%，无法奔跑 |
| > 100% | 无法移动，只能缓慢爬行 |

## 六、社交与贸易属性

| 属性 | 公式 |
|------|------|
| **声望** | 初始 0，完成任务 +5~+50，击杀 NPC -20~-100，每交易 100 金币 +1 |
| **商店折扣** | `声望 / 1000`（声望 100 → 10% 折扣） |
| **魅力** | `WIL × 0.5 + PER × 0.3 + 装备加成` |
| **说服成功率** | `魅力 × 2% + 声望 × 0.1% - 目标敌意值` |
| **恐吓值** | `击杀数 × 0.5 + 装备威慑值 + 恶名声望` |

## 七、隐藏/特殊属性

### 幸运（隐藏）

| 项目 | 公式 |
|------|------|
| **幸运值** | `5 + PER × 0.2` |
| **稀有掉落加成** | `幸运 × 0.5%` |
| **暴击额外加成** | `幸运 × 0.1%` |
| **有利事件概率** | `基础概率 + 幸运 × 0.3%` |

### 疲劳度

| 项目 | 值 |
|------|------|
| **上限** | 100 |
| **清醒累积** | 0.5 点/游戏小时 |
| **剧烈运动** | +0.3 点/分钟 |
| **睡眠恢复** | -10 点/游戏小时 |

| 阈值 | 惩罚 |
|------|------|
| ≥ 50% | 所有属性效率 -10% |
| ≥ 70% | 所有属性效率 -25%，精神流失加速 |
| ≥ 90% | 所有属性效率 -50%，可能"微睡眠"（失去意识 2 秒） |

### 感染值

| 来源 | 值 |
|------|------|
| 野兽咬伤 | +15 ~ +40 |
| 接触污染物 | +5 ~ +20 |
| 未处理伤口 | +2/游戏小时 |

| 阈值 | 惩罚 |
|------|------|
| ≥ 30% | 持续掉血 0.5/分钟，体力恢复 -20% |
| ≥ 60% | 持续掉血 2/分钟，所有属性 -15% |
| = 100% | 败血症，持续掉血 5/分钟，10 分钟内死亡 |

自然恢复：0.1 点/游戏小时（极低），主要靠药物降低。

### 营养均衡度

`min(蛋白质达标率, 碳水达标率, 维生素达标率) × 100%`

| 营养素 | 每日需求 |
|--------|---------|
| 蛋白质 | `STR × 2 + CON × 3` 克/天 |
| 碳水 | `CON × 5 + 运动消耗 × 0.3` 克/天 |
| 维生素 | 50 单位/天 |

| 均衡度 | 效果 |
|--------|------|
| ≥ 80% | 所有恢复速率 +10% |
| 50%~80% | 无额外效果 |
| 20%~50% | 最大 HP -10%，体力恢复 -20% |
| < 20% | 最大 HP -25%，体力恢复 -40%，疾病抗性 -30% |

## 八、属性联动关系图

```
地域背景基线 + 天赋修正
        │
        ▼
   ┌──────────────────────────┐
   │    六大基础属性           │
   │  STR  AGI  CON            │
   │  INT  PER  WIL            │
   └────────┬─────────────────┘
            │ 推导
     ┌──────┼──────┬──────────┬──────────┐
     ▼      ▼      ▼          ▼          ▼
  生存属性 战斗属性 环境适应   社交属性   隐藏属性
  HP/Stamina 伤害/防御 御寒/负重 声望/魅力 幸运/疲劳
  饥饿/口渴 暴击/命中 水分抗性 话术/恐吓 感染/营养
  体温/精神 攻速/先手 毒素抗性 商店折扣  感染值
```

**设计原则**：基础属性决定上限，生存属性维持存活，战斗属性对抗威胁，环境属性对抗自然，隐藏属性增加变数。角色差异来自地域背景（生长环境），而非种族天赋——所有人都是人类。
